# Manual de uso de BIBLIOTECH

## Biblioteca Escolar CCTL

BIBLIOTECH permite administrar alumnos, docentes, libros, préstamos, devoluciones, etiquetas, reportes y respaldos.

## Iniciar el sistema

1. Hacer doble clic en el acceso directo BIBLIOTECH.
2. Esperar a que se abra el navegador.
3. No cerrar la ventana azul mientras se utiliza el sistema.

## Registrar un préstamo

1. Ingresar en Registrar préstamo.
2. Seleccionar Alumno o Docente.
3. Escribir la cédula.
4. Verificar el nombre del beneficiario.
5. Escribir el número de inventario del libro.
6. Verificar el título y disponibilidad.
7. Presionar Registrar préstamo.

La devolución prevista se calcula automáticamente a cinco días hábiles.

## Registrar una devolución

1. Ingresar en Préstamos.
2. Buscar por cédula, nombre, título o inventario.
3. Presionar Devolver.
4. Verificar la fecha real de devolución.
5. Seleccionar la condición del libro.
6. Escribir una observación si corresponde.
7. Confirmar la devolución.

## Registrar un libro nuevo

1. Ingresar en Libros.
2. Presionar Registrar libro.
3. Completar los datos bibliográficos.
4. Guardar el libro.
5. Agregar el ejemplar físico.
6. Verificar el número de inventario automático.
7. Completar estantería y balda.
8. Imprimir las etiquetas.

## Importar libros

1. Utilizar solamente la plantilla oficial.
2. Ingresar en Libros.
3. Presionar Importar desde Excel.
4. Seleccionar la planilla.
5. Revisar la vista previa.
6. Corregir los errores indicados.
7. Confirmar la importación.

## Imprimir etiquetas

El sistema permite:

- Etiqueta individual.
- Etiquetas en mosaico.
- Etiqueta de lomo individual.
- Etiquetas de lomo en mosaico.

Antes de imprimir, verificar clasificación, signatura, estantería y balda.

## Alumnos

Desde Alumnos se puede:

- Buscar alumnos.
- Registrar alumnos.
- Editar datos.
- Consultar historial.
- Importar la lista oficial.
- Filtrar por estado y año.
- Consultar egresados.

## Promoción anual

La promoción debe ejecutarse solamente al finalizar el año lectivo.

Orden correcto:

1. Registrar las devoluciones pendientes.
2. Crear un respaldo.
3. Revisar las cantidades por curso.
4. Confirmar la promoción anual.
5. Importar la lista oficial del nuevo año.
6. Revisar alumnos nuevos, actualizados y ausentes.

Los alumnos de tercer curso quedan como egresados y no son eliminados.

## Respaldos

El sistema crea un respaldo al iniciarse.

También puede crearse un respaldo desde el dashboard.

Los respaldos se guardan en:

backups

No eliminar los respaldos recientes.

## Cerrar el sistema

1. Cerrar el navegador.
2. Volver a la ventana azul.
3. Presionar CTRL+C.
4. Confirmar la detención si se solicita.

## Recomendaciones

- No borrar db.sqlite3.
- No modificar archivos del sistema.
- No apagar la computadora durante una importación.
- Crear un respaldo antes de una promoción o importación grande.
- Informar cualquier mensaje de error al administrador.
